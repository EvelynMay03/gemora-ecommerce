# 💎 Gemora E-commerce System

### E-commerce Website | Academic Project

## 📖 About the Project

Gemora is an e-commerce website I developed as an academic project during my NCC Level 5 Diploma in Computing at Strategy First College.

The website is designed to provide an online shopping experience where customers can explore products, manage their shopping carts, and place orders.

Through this project, I gained practical experience in backend development, database management, and building interactive web applications.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Interactive functionality
- **PHP** – Backend development
- **MySQL** – Database management
- **Bootstrap** – Responsive design

## ✨ Key Features

- User registration and login
- Product categories and browsing
- Product variants, including sizes and colors
- Shopping cart functionality
- Wishlist and product reviews
- Order placement and checkout
- User profile management
- Admin and customer sections

## 🚀 How to Run

1. Install a local PHP and MySQL environment, such as XAMPP or MAMP.
2. Place the project folder inside your local web server's document directory.
3. Import `database/query.sql` into MySQL.
4. Configure the `DB_HOST`, `DB_NAME`, `DB_USER`, and `DB_PASSWORD` environment variables.
5. Start your local web server and MySQL.
6. Open the project through your local server.

**Note:** The database schema does not include customer records or product data. Some features require data to be added before testing.
